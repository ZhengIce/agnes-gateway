# **Agnes AI 隐私政策**

生效日期：\[2026年4月1日]

更新日期：2026年7月9日

本隐私政策（“本政策”）说明 Agnes AI（“我们”或“我们的”）在您访问或使用我们的网站、平台、应用程序编程接口（“API”）、人工智能（“AI”）模型、软件应用程序、开发者工具及相关服务（统称“服务”）时，如何收集、使用、存储、传输、披露和保护个人及非个人信息。

本政策还说明了您的隐私权利和选择，包括符合条件的用户如何在相关退出功能可用的情况下，选择退出将特定交互用于 AI 模型改进。

通过访问、浏览、注册或使用服务，即表示您确认已阅读并理解本隐私政策。如果您不同意本政策，请不要使用服务。

## **1. 本政策的适用范围**

本政策适用于访问或使用服务的所有个人和实体，包括访问者、用户、开发者、客户、企业客户及最终用户，以及在服务相关过程中被处理其信息的个人或实体。

本政策涵盖：

● Agnes AI 官方平台和网站，包括所有子域名及相关网页；

● Agnes AI 提供的 API、SDK、开发者工具、控制台、文档及相关技术服务；

● 由 Agnes AI 开发、拥有或运营的应用程序、插件、集成、模型和服务，无论通过网页、移动端、API 或其他界面访问；

● 您与 Agnes AI 之间的通信，包括支持请求、反馈、电子邮件、调查和应用内消息；

● 您、您的组织、您的用户或代表您在使用服务时提交的信息、内容、提示、输入、输出、文件及其他数据。

本政策不适用于：

● 非 Agnes AI 拥有或控制的第三方服务、产品、平台、应用程序、支付处理商、云服务提供商、分析服务提供商、社交登录提供商或集成服务；

● 链接至服务或从服务链接出去的外部网站或应用程序；

● 第三方独立于 Agnes AI 收集的信息；

● 无法合理用于识别个人身份的匿名或聚合信息。

您对第三方服务的使用受该等第三方的隐私政策和条款约束。

## **2. 定义**

● **个人信息**：指能够识别、涉及、描述、可合理关联或可合理链接至已识别或可识别个人的信息。这可能包括姓名、电子邮箱地址、电话号码、公司名称、职位、账单信息、邮寄地址、账户标识符、IP 地址、设备标识符及其他唯一标识符。

● **敏感个人信息**：指根据适用法律可能受到更高保护的个人信息类别。这可能包括财务信息、政府签发的身份证件号码、健康信息、生物特征数据、精确位置信息、种族或民族来源、宗教或哲学信仰、政治观点、工会成员身份、与未成年人相关的信息，以及适用法律定义为敏感信息的其他类别。

● **客户内容**：指您、您的组织、您的用户或代表您通过服务提交、上传、传输、生成或以其他方式提供的内容。客户内容包括提示、输入、输出、文件、文档、图像、音频、文本、代码、消息、用户生成内容及通过服务处理的其他材料。

● **客户数据**：指由客户或代表客户提交的数据、内容和信息，包括客户内容、账户相关数据、业务信息以及与客户使用服务相关的使用数据。

● **使用数据**：指您使用服务时自动收集的数据，包括 API 调用日志、交互记录、会话数据、系统活动、模型使用指标、设备信息、浏览器信息和性能数据。

● **免费服务**：指 Agnes AI 提供的免费服务层级、访问计划、试用、推广访问、免费 API 层级、免费开发者访问或其他无成本服务。

● **企业服务**：指 Agnes AI 根据企业协议、主服务协议、订单、数据处理协议或其他经协商的商业安排提供的服务。

● **付费 Token 计划**：指 Agnes AI 提供的付费用量计划、积分计划、Token 计费计划、订阅计划或其他付费商业访问计划，不包括免费服务。

● **匿名化数据**：指经过处理后无法合理用于识别个人身份的数据，无论单独使用或与其他信息结合使用均无法合理识别个人。

● **聚合数据**：指与多个用户或客户的数据合并并以不识别任何个人或客户的方式汇总的数据。

● **Cookies**：指存储于或访问自您设备的小型文本文件或类似技术，用于识别您的浏览器或设备、记住偏好、支持安全并了解服务使用情况。

您在使用服务时可能选择向我们提供某些信息，包括：

● **账户信息**：当您创建或管理 Agnes AI 账户时，我们可能收集您的姓名、电子邮箱地址、公司名称、职位、用户名、密码、账户设置和身份验证信息。我们使用这些信息创建和管理您的账户、验证您的身份、维护账户安全并与您沟通。

● **支付和账单详情**：如果您订阅付费计划或购买 Agnes AI 的服务，可能需要提供信用卡信息、账单地址、税务信息、发票、交易记录及相关支付详情。在使用第三方支付处理商的情况下，我们通常不会直接存储完整支付卡信息。支付信息可能由第三方支付处理商根据其隐私政策、安全标准和适用法律进行处理和存储。

● **通信内容**：当您联系我们的支持团队、提交咨询、提供反馈、参与调查、通过电子邮件或应用内渠道与我们沟通，或以其他方式与我们互动时，我们可能收集该等通信内容、联系信息及相关元数据。我们使用这些信息回应请求、提供支持、解决问题、改进服务并保留通信记录。

● **您提交的内容**：您在使用服务时提交的任何内容，包括但不限于提示、输入、文件（例如文档、图像、音频）和其他用户生成内容。该等内容用于提供您请求的 AI 功能，例如生成响应、分析数据。

○ **免费服务**：对于使用我们免费服务的用户，包括免费 API 层级，您与服务的交互可能会被用于改进我们的产品和 AI 模型，除非您在相关退出功能可用的情况下选择退出。

○ **企业服务和付费 Token 计划**：对于企业客户和付费 Token 计划用户，客户内容默认不会用于训练或改进我们的 AI 模型。只有在您明确授权，或在适用情况下由您的组织明确授权时，该等内容才会用于上述目的。

● **可选信息**：您可以选择提供其他信息，例如头像、偏好设置、组织详情、角色信息或产品兴趣。该等信息为可选信息，可能用于个性化或改进您的体验。

### **3.2 自动收集的信息**

当您访问或使用服务时，我们可能自动收集使用数据和技术信息，包括：

● **设备信息**：设备类型、操作系统、浏览器类型和版本、IP 地址、设备标识符、由 IP 地址推断的大致位置、语言设置及其他技术信息。

● **使用数据**：您与服务交互的日志和记录，包括 API 调用、时间戳、请求和响应元数据、延迟、错误日志、功能使用情况、访问页面、会话时长、模型使用情况、Token 使用情况及其他运营指标。

● **Cookies 和类似技术**：通过 Cookies、本地存储、像素、网络信标、SDK 或类似技术收集的信息。这些技术帮助我们进行用户认证、维护会话、记住偏好、分析使用情况、检测滥用并改进服务。

● **安全与诊断数据**：认证日志、访问日志、系统日志、欺诈指标、滥用信号、崩溃报告和诊断信息，用于维护服务的安全性、可靠性和完整性。

### **3.3 第三方数据**

## **6. Cookies 和跟踪技术**

我们使用 Cookies 和类似技术来运营服务、提升用户体验、改进性能并维护安全。

### **6.1 Cookies 类型**

● **必要 Cookies**：服务正常运行所必需的 Cookies，包括身份验证、会话管理、安全、欺诈预防和访问安全区域。

● **性能 Cookies**：用于收集用户如何与服务交互的信息，例如页面访问、功能使用、错误、延迟和性能指标。

● **功能 Cookies**：用于记住偏好和设置，例如语言、地区、登录状态、界面偏好及其他个性化选择。

● **分析 Cookies**：用于了解使用模式、衡量流量、分析功能采用情况并识别需要改进的领域。在法律允许的情况下，我们可能使用第三方分析工具。

### **6.2 管理 Cookies**

大多数浏览器允许您通过浏览器设置控制、删除或阻止 Cookies。如果您禁用某些 Cookies，服务的部分功能可能无法正常运行。

我们不会使用 Cookies 出售您的个人信息，也不会为了第三方定向广告目的收集信息。
